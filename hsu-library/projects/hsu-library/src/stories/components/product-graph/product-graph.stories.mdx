## Product Graph in a Edge Case

One of the known bugs with the current implementation is that the step hover can be rendered incorrectly.
This is visible when hovering over the center of the (i) icon right next to the "Montiertes Gestell" or
"Fertige Glasplatte" where the hover will then show a different step instead of the one that should be actually hovered.

<Canvas withToolbar>
    <Story name="Edge Case" args={{
        ...advancedGraphData,
        steps: [

            {

                start: 4,
                end: 11,
                producerId: 100,
                productId: 1
            },
            {
                stepId: 5,
                start: 6,
                end: 11,
                producerId: 100,
                productId: 1
            },
        ]
    }}>
        {Template.bind({})}
