> **Note**: The margin @Input() utilizes the `CMargin` class to replicate the behavior of CSS margins.\
> For instance, in CSS, we often use declarations like `margin: 30px 60px;` or `margin: 10px 30px 20px;`.\
> So by using CMargin class, you can achieve the same effect by using `new CMargin(30, 60)` or `new CMargin(10, 30, 20)`.\
> This provides a more structured and programmatic way to manage margins within your application.
